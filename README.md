# Sales Performance Analysis | Power BI

## Project Overview

This project is an interactive sales performance analysis developed using Microsoft Power BI and Excel.

The project transforms raw sales data into an interactive dashboard that provides insights into sales performance across products, customers, categories, regions, and time.

## Dashboard

The Power BI dashboard provides an overview of:

- Total Sales
- Total Quantity
- Total Orders
- Average Order Value
- Sales by Category
- Sales by Region
- Sales Trend Over Time
- Top 10 Customers by Sales
- Top 10 Products by Sales

## Interactive Features

The dashboard includes:

- Date range filtering
- Region filtering
- Category filtering
- Interactive visual cross-filtering

Users can select a category, region, or date range and the dashboard automatically updates the relevant metrics and visualizations.

## Data Preparation

The dataset was prepared using Excel before being imported into Power BI.

Data preparation included:

- Cleaning and standardizing date values
- Creating a cleaned date column
- Checking and organizing the dataset
- Preparing tables for analysis

## Data Modeling

Power BI was used to create relationships between:

- Customers
- Orders
- Products

The model was then used to build interactive visuals and calculations.

## Tools Used

- Microsoft Excel

- Data Cleaning
- Data Transformation

## Key Business Questions

This analysis helps answer questions such as:

1. Which product categories generate the most sales?
2. Which regions perform best?
3. Which customers generate the highest sales?
4. Which products are the top performers?
5. How do sales change over time?
6. How does sales performance change when filtering by category, region, or date?

## Files

- `Sales Data Analysis.xlsx` — Excel dataset and data preparation.
- `Sales Performance Dashboard.pbix` — Interactive Power BI dashboard.

## Project Purpose

The purpose of this project was to practice transforming raw sales data into a structured business intelligence solution and communicate insights through an interactive dashboard.
